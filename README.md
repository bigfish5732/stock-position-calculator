# 📈 股票仓位计算器

一个手机可直接打开、多设备数据同步的股票仓位规划工具。核心解决：**本金怎么分仓、单票买多少、分批怎么买、止损止盈怎么做、超仓自动提醒**。

## 功能

- 用户注册 / 登录（数据按账号隔离，换设备登录同一账号即可同步）
- **首页**：输入总金额 → 自动算出最多买几只、单票仓位上限（百分比 + 金额）
- **单票计算**：输入股票名、当前价、止损/止盈比例、加仓次数等，一键算出：
  - 单票最大仓位（可买股数、占用金额、占本金比例）
  - 分批买入计划（第一次 / 第二次 / 第三次…，**加仓次数为 0 时只买一次**）
  - 止损方案：止损价、止损回撤金额、分批止损（先减仓少亏）、完全止损（全卖）
  - 止盈方案：止盈价、全仓止盈盈利、分批止盈（先卖一部分锁利润）、保留底仓
- **我的持仓**：保存计算结果，单票/总仓位超仓自动标红提醒
- **设置**：本金、最多股票数、单票仓位上限、每手股数（A股 100 / 美股港股 1）
- 移动端自适应，手机浏览器可直接使用

## 技术栈

Node.js + Express + SQLite（Node 内置 `node:sqlite`，无原生依赖），前端原生 HTML/CSS/JS，零构建、轻量、好部署。

## 本地运行

要求：Node.js ≥ 18。

```bash
npm install
npm start
```

浏览器打开 <http://localhost:3000>，手机连同一 Wi-Fi 也能用局域网 IP 访问。

数据保存在 `./data/app.db`（可用环境变量 `DATA_DIR` 修改路径）。

## 部署到托管平台（电脑关机也能用、手机随时打开）

> 前提：把本项目先推到一个 GitHub 仓库。

### 方式一：Railway（推荐，数据永久保存）

1. 登录 [railway.app](https://railway.app) → New Project → **Deploy from GitHub repo**，选本项目。
2. Railway 会自动识别 `Dockerfile` 并部署。
3. **关键一步：挂载持久化卷**（不挂的话重启会丢数据）：
   - 项目 → 你的服务 → **Volumes** → **Add Volume** → 挂载路径填 `/data`
4. 服务 → **Variables** → 添加：`DATA_DIR` = `/data`
5. 打开 Railway 分配的域名（手机也能直接打开）。

### 方式二：Render（免费，但注意磁盘）

1. 登录 [render.com](https://render.com) → New → **Web Service** → 连 GitHub 仓库，自动识别 `Dockerfile`。
2. 环境变量：`DATA_DIR` = `/data`（默认已写在 `render.yaml`）。
3. ⚠️ Render 免费版的磁盘是**临时盘**，每次重新部署/重启会清空数据。
   想要永久保存，需加购 Persistent Disk（付费），或改用 Railway 挂卷。

## 计算说明（默认参数）

- 单票仓位上限：默认 20%（可在「设置」改）
- 加仓次数：0 = 不分批，只买一次；填 N 就分 N+1 次买入
- 止损 / 止盈比例：默认 10% / 20%
- 分批止盈：涨到止盈价先卖 50% 锁定利润，保留 50% 底仓继续博上涨
- 分批止损：跌到止损价先减仓 50% 少亏；若继续下跌、无反弹迹象且基本面恶化，就全卖（完全止损）

> ⚠️ 本工具只做仓位规划与风险测算，计算结果不构成投资建议，股市有风险，入市需谨慎。
